# NHQM Clean Up — Windows System Optimization Tool

**NHQM Clean Up** is a Windows cleaning and optimization utility developed in Python to improve system maintenance, remove unnecessary files, and free up disk space.

The tool features a custom RGB-styled command-line interface (CLI), automated cleanup operations, storage analysis, and detailed reports.

### Key Features

- Windows temporary file and cache cleanup.
- Support for Discord, Steam, Chrome, Edge, and Brave.
- Individual and complete cleanup options.
- Disk space analysis and cleanup reports.
- Confirmation before deleting files.
- Automatic handling of locked or inaccessible files.
- Protection of important user data and system files.
- Lightweight operation without additional Python dependencies.

**Technologies:** Python, Windows CMD, File System Management, System Automation.

**Project Goal:** Deliver a reliable, lightweight, and efficient Windows maintenance utility focused on performance, usability, and safe system cleanup.
